# まいにち食費

日々の食費を記録し、月合計・前月比・食料品と外食の内訳を確認できるシンプルなWebアプリです。

## 使い方

- `index.html` を静的サイトとして公開します。ビルド手順はありません。
- レシート読取では、端末のカメラまたは画像ファイルから日付・金額・店名を読み取ります。結果を確認・修正してから保存してください。
- 記録はブラウザのローカルストレージに保存されます。端末・ブラウザ間の同期やバックアップはありません。
- OCRエンジンは初回利用時にTesseract.jsをCDNから読み込みます。

## 公開

GitHub Pagesで公開する場合は、このフォルダの内容をリポジトリのルートに置き、リポジトリ設定の Pages から `main` ブランチの `/ (root)` を公開元に選択してください。
